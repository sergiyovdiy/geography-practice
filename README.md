# Електронний практикум з географії · 10 клас

Авторський набір інтерактивних практичних робіт **для учнів 10 класу**.

Електронний практикум створено для очного й дистанційного навчання та **постійно розширюється**: упродовж навчального року до колекції додаватимуться нові практичні роботи, а вже опубліковані матеріали можуть оновлюватися й удосконалюватися.

## Для чого цей ресурс
- практичні роботи з географії для 10 класу;
- очне та дистанційне навчання;
- робота у браузері без реєстрації;
- адаптивний інтерфейс для комп’ютера і смартфона;
- формування PDF / TXT звіту для перевірки вчителем;
- використання у Google Classroom, Moodle, Microsoft Teams та інших середовищах.
